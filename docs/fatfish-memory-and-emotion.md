# 本机记忆、情绪与关系模块

2026-11-23。实现位于 `qqbot/fatfish_extensions/`，为本项目自行实现，依据 FatFish 公开的接口与设计说明，不能称为作者的私人内核。

## 生效与持久化

Mac 适配器在导入上游 bot/panel 前安装 memory、mood2、soul、galgame 的实现，机器人与原控制台使用相同模块和数据格式。发布包仍是 qqbot/；Mac 更新器按提交把扩展放到私有 extensions/<SHA>/，切换 current 链接后重启聊天/面板，账号容器保持。上游更新独立保存；导入检查也加载本机扩展，避免上游恢复空壳或接口变化后带病切换。

数据在 FatFish 私有 data/，不在 Git。部署前整份数据备份在私有 core-backup-20261123.tar.gz。JSON 写入使用进程与文件锁、临时文件、fsync 和原子替换；读到损坏数据会报错，不用空记录覆盖。

## 记忆

- 以对话文件和发言 QQ 号隔离，保留消息ID/原文证据及来源时间；同名账号不会混同。模型提炼只能引用本批真实用户消息行，机器人发言、虚构行号和不匹配账号不作为事实。
- 支持长期事实、近况、经历；后台批量提炼，@后明确“记住我……”可立即记录。密码、密钥和修改系统规则的内容不进入记忆。
- 同一人的明确更正可取代旧事实，旧条目标为 superseded 并留来源。不能用一人的更正覆盖另一个人。
- 每日/每人/每群配额与本机持久化一起执行；显式记住和有证据更正保留单独通道。召回按当前发言账号、话题相关度与清晰度筛选，不混入别人的私聊事实。
- 清晰度按半衰期衰减；模糊记忆会注明需要确认，真正再次提到才强化，12小时内不重复强化。支持钉住、取消钉住、归档、找回；遗忘操作保留阻止原事实重新提炼的墓碑和相似内容匹配。“别忘了”不会被误当成删除指令。
- 夜间可将快淡忘、同一归属的事实压缩为有来源的印象，原细节归档；不会把性格诊断当事实。召回与遗忘是工程启发式，不能承诺任意改写的同义句都能完美识别。

## 情绪、熟悉度和连续性

情绪裁判独立于回复，每次只记有用户原文证据的客观互动；异常输出不落盘。情绪增减限幅、重复同向互动递减，心情逐步回到70，情绪强度更快回落。分数仅供内部状态和控制台显示，不指令机器人辱骂、冷落或评价用户人格。事件只进入原对话的提示词，删除用户数据途中完成的裁判结果会放弃。

熟悉度按账号持久化，变化限幅、至少间隔30分钟、每日增长有上限；不影响正常求助的公平回应。保留本人明确提出的“别再提某事”边界，可由控制台查看/撤销。关系卡保存本对话主题和轮数；上游前情提要接口现在会根据原始对话实际压缩，不再是空函数。

每天有真实互动才生成本地日记；梦境明确标为虚构。日记、梦境不作为事实记忆，不自动发表到群或QQ空间，也不带进其他群的提示词。自我笔记可在面板管理，不覆盖系统规则、权限和人格底线。
