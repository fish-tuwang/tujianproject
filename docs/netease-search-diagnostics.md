# 网易云搜索与自检诊断

2026-11-23。本机实测已登录凭据确实带入请求。搜索《晴天－周杰伦》时，HTTP 200、业务码200、返回15条，但7条歌名/版本不符、8条歌手不符，没有明确匹配指定原唱的候选。原版 ne_search 先过滤再返回，_search 把候选数当原始数，自检因此错误显示“什么都没搜到”。这是本次已确认的原因，不能由此直接推定登录失败、会员不足或平台版权情况。

对照《平凡之路－朴树》返回15条、匹配5条，登录凭据下能取得播放地址，未返回试听标记。本次仅核对搜索与播放地址，不能等同于任意歌曲都能播放或完成整曲音频验收。

实现 `qqbot/fatfish_extensions/music_search.py`，通过扩展安装到 bot 和 panel 共同使用的上游 music 模块，不直接修改上游发布目录。保留严格的歌曲、歌手和版本匹配，不将名字为 Jay 的任意歌手当成周杰伦，不拿翻唱或同名歌曲冒充原唱，不绕过播放权限。

诊断区分：网络/超时、HTTP错误、平台业务码拒绝、响应结构异常、明确abroad限制、实际0结果、有结果但无符合原唱、匹配成功。自检保留原始返回数和过滤后数，不再将过滤失败说成未搜索到。来源上方显示“已就绪”，表示具备调用条件；自检显示“本次通过/本次未通过”，只代表本次完整搜索/播放测试，不混淆两个阶段。

私有 `data/music-search-status.json` 只存最近一次时间、状态码、计数、分类和“是否使用登录”布尔值，不保存cookie、令牌、完整返回、播放地址或聊天内容。源码更新不退出、覆盖或刷新网易云账号；既有B站等回退顺序保留，无法匹配指定原唱时仍可回退。

发布随 qqbot 自动更新，不新增依赖、不改登录库。上游接口变更会在导入适配检查时阻止不兼容更新。验收覆盖真实API响应、凭据是否携带、严格匹配、自检计数和各类错误分开显示；测试不向QQ发消息。
