# 按真实模型统计用量

2026-11-23。实现：`qqbot/fatfish_extensions/usage.py`、`usage_ui.py`，随普通 QQ 的 qqbot 自动更新部署。保留原账号、模型、密钥和私有数据；新增私有 `data/model-usage.json`，旧 `stats.json` 不迁移、不清空，回滚代码后新账本仍保留。

## 统计口径

- 从真实 `/chat/completions` 成功响应读取 `model`、`usage`，按实际模型、输入档位和思考模式分别累计；请求的模型别名单独保留。ContextVar 隔离并发请求，避免把上一轮模型或用量套过来。只记录计数和价格快照，不存提示词、正文、媒体、接收人、API key 或带凭据 URL。
- 读取千问 `prompt_tokens_details.cached_tokens`，缓存是输入的子集，不能额外再加一次；输出包含 reasoning tokens，思考数量只作其中的分项。
- 当前已核对北京 `dashscope.aliyuncs.com` 的 qwen-plus / latest / 2025-12-01 阶梯和 2025-07-14、2025-04-28 固定输入单价。计费 K=1000，按整次请求的输入总量选档，不逐段累进。按模型和模式区分输出单价；隐式缓存命中按输入单价的20%估算。
- 不将 DeepSeek 峰谷翻倍、缓存价、余额接口或搜索单价套到千问。原聚合计数同步修正缓存字段，新增模型费用用于已追踪模型估算和新调用的预算计量。
- 费用是按调用时核对的公开单价估算；促销、赠送额度、Token Plan 和云端实际扣费只有云账单能确认。未知模型/地域、缺失 usage、未支持的显式缓存创建收费标记为未计价，不将零元伪装成免费。计价记录保留来源和核对日期，公开价格调整需要更新规则并验证。
- 旧数据没有模型、每次请求输入档位和真实缓存资料，作为未归属历史调用保留，不用当前模型重算成“真实费用”。隔离 API 验收若调用真实模型，会以“统计验收”记录实际 usage；不会写入模拟消费。

## 页面与验收

控制台“用量和余额”“统计”显示当前配置模型、实际响应模型分组、输入/缓存/输出/思考 Token、功能分组、每日费用、未计价调用及历史未归属记录。主要费用用人民币展示。余额提供百炼账单入口，不伪造余额；本页模型费用不含语音/动画等外部服务。

自动检查覆盖：缓存不重复计数、128000/256000 档位边界、思考价格、未知模型/地域、实际响应模型与别名、原数据保留、预算不使用DeepSeek价格、面板脚本语法。隔离沙箱不向 QQ 发消息。发布前备份原统计，发布后用真实 API usage 做一次端到端核验，检查本机在线、API账本和页面。
