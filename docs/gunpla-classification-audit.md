# 高达作品分类核对（2026-11-19）

## 核对范围与证据

- 实时核对万代中国官网 `/gunpla` 的全部 39 个作品入口，串行读取全部 162 页作品列表，记录 1,440 个商品 ID 与作品的关联，零读取错误。列表含当前数据库尚未导入的商品；本次不凭列表补造商品价格、详情或图片。
- 比对京东现存完整采集快照的 1,208 个模型记录（coverage=complete），发现 156 个作品字段为空。该快照不等于未经直接读取的 Mac 当前数据库。
- 原有 39 项年代表维持已确认的“动画作品首次播出/上映；非动画按首次公开”规则。官方动画目录的稳定日期逐项对比既有证据；小说改编动画的公开年份未被擅自换成原著出版年份。海盗高达补为 1994 年漫画连载，证据为 KADOKAWA 出版方说明。
- 官网列表无法修补所有缺项：普通 FAZZ 的列表和作品链接均漏填，但其正文明确写明《高达前哨战》。不能把“在官方 ZZ 列表找不到”认定为漏采 ZZ。

## 修复结果

对上述存量快照验证：133 个模型关联补正；9 个明确非高达作品模型或独立支架从高达模型列表排除；剩余 14 个官方证据未确认的模型独立保留在“跨界／其他企划／作品待核对”。修复后 1,199 个可见模型全部可从作品入口访问，不声称剩余 14 个已完成作品归属确认。

补入《0083》《第08MS小队》《∀高达》《W 无尽的华尔兹》《SEED 观星者》《MS IGLOO》《暮光的阿克西斯》《SEED ASTRAY》《复仇的安魂曲》《MSV》《THE BLUE DESTINY》等已核实的作品。SD、联名及非影视企划单列；尚未取得确切首次公开日期的企划不硬塞入某个年代。

FAZZ Ver.Ka（2372）、Ex-S/S 高达（2194）、深度强袭（3525）归入高达前哨战；FAZZ 不放入 ZZ。原始数据库 JSON、图片、价格、账号和数据卷均不修改。通过带商品 ID、名称校验及证据的查询投影补正，Mac 更新 backend 后即可对已有记录生效，无需数据库迁移。作品筛选仍合并普通及限定、保留规格和比例筛选规则。

分类表及年代表共同参与缓存版本计算，旧 Redis API 结果与摘要不会掩盖新分类。以后采集解析支持作品列表上下文与详情链接合并；同步脚本在规格列表之外交叉读取作品列表，但独立安装在 Mac 的自动更新器目前只更新 backend，独立采集脚本的发布仍需按其部署方式处理。
