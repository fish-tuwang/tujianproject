# 远程 QQ 登录二维码

2026-11-23。入口为图鉴所有者专用 `/qq-panel/qq-login`。

需要登录时自动显示二维码。图片使用同源、带原图鉴鉴权的 `/qq-panel/qrcode?t=...`；宿主适配器从正在运行的账号容器 `/app/napcat/cache/qrcode.png` 只读取得当前 PNG，验证格式并禁用缓存，不依赖宿主旧副本、data URI 或临时 blob URL。总览的二维码同用该路径。未登录或其他账号仍不能访问。

点击“需要登录时获取新二维码”才请求 QQ 刷新；按钮本身表达此操作，不再额外弹出易阻塞的浏览器确认框。服务端继续验证同源、所有者、X-Panel 与确认标志。刷新要等图片实际变化并验证 PNG，失败明确提示，不返回旧码冒充新码；不重启 QQ、不删除登录目录。查看现有图片是只读操作，不会自动循环刷新 QQ 登录。

图鉴会话失效会隐藏二维码、清除旧的在线提示并提供重新登录入口。图片加载有超时和错误提示，手机端显示清晰放大的像素图。QQ 已在线时隐藏二维码，不强行重新登录。

验收：自动显示、显式刷新、图片同源路径、会话失效、容器当前图片与旧副本区分、PNG 校验，以及远程页面图片自然尺寸非零。二维码和截图仅留本机私有/忽略目录，不提交 Git。图片能显示不代表已扫码成功；QQ 最终登录仍由本人在手机确认。
