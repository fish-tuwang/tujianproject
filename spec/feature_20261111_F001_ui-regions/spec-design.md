# 双图鉴圆角主题与宝可梦地区浏览

2026-11-11。用户要求参考Worktile截图改善圆角与色彩，保留现有图标，多美卡使用相关背景；宝可梦按地区查询，去掉反复点击“继续探索”。用户明确选择地区图鉴收录，同一宝可梦允许跨地区重复。持续授权直接实现、部署并交付页面效果，不新增确认门槛。

## 方案

沿用现有FastAPI、PostgreSQL、Redis、浏览器预览及原生小程序，不替换框架。深色侧栏配圆角白卡、彩色标签；多美卡暖色渐变横幅与矢量赛道/车库背景，宝可梦蓝绿横幅与图鉴/探索主题背景。保留所有既有图标、原图和来源。主题背景是本地矢量装饰，不对商品照片作AI修改。

地区索引覆盖关都、城都、丰缘、神奥、合众、卡洛斯、阿罗拉、伽勒尔、洗翠、帕底亚。通过PokéAPI的region.pokedexes与pokemon_entries构建离线集合，合并同地区各版本图鉴并去重；允许跨地区重叠，保留对应来源和采集日期。列表与详情仍使用现有52poke资料和全国编号。地区元数据随发布离线提供，不让用户浏览时访问外站；不修改数据库记录或编号。地区接口返回名称和各索引版本，页面解释“同地区各版本图鉴合并收录”。

增加region参数，地区、属性、名称/编号共同筛选；地区索引限制为有限受支持键。API缓存键和游标绑定地区，未选择地区时兼容旧游标。返回筛选后总数。地区筛选不会出现在多美卡页面；多美卡品牌/年份不会出现在宝可梦页面。

移除浏览器“继续探索”按钮，使用接近列表底部的哨兵自动加载下一批。复用既有游标和请求序列，防止重复请求、过期响应、重复卡片；详情/放大图打开期间及恢复历史列表期间暂停自动加载。仅在进入哨兵或有新的滚动动作时推进一批，防止无交互循环把1025条全拉完；窄屏内容不足一屏时允许补齐可见区域。保留网络错误重试，加载下一批失败时保留已显示卡片。详情关闭、浏览器刷新、两个图鉴切换继续恢复地区/属性/搜索/已加载进度与位置，显式重置取消旧恢复。小程序已有onReachBottom，增加地区选择并同步圆润主题。

2. backend/preview/index.html、style.css、app.js与本地SVG背景；miniprogram/lib/page-factory.js、services/api.js、app.wxss和宝可梦列表WXML：圆润主题、地区控件、自动浏览与状态恢复，保留旧卡片填满、关闭按钮居中、原图放大和20/40/60/100多美卡分页。
3. 本地完整Python与Node测试，真实浏览器桌面/移动布局截图；滚动自动加载超过三批、地区/属性组合、去重、最后一批停止、网络失败保留已载内容、详情打开暂停与返回位置、刷新恢复、显式重置竞态、Tomica历史回归。通过现有带审计的发布脚本部署0.9.0，检查双API、原插件与缓存守护进程，不做数据库迁移或重新采集照片。
