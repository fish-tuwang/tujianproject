# Feature: 20261111_F003 - gunpla-catalog

## 需求背景
在现有私有多美卡/宝可梦图鉴中加入万代高达模型，首版直接实现、测试并部署到现有服务器供用户调整。用户确认：采集“更多品牌”展开后的模型规格，不采配件；作品按首次播出/公开年代分组。继续沿用已授权的直接执行和GitHub同步流程，不重复申请设计/部署许可。

## 目标
- 官网gunpla首页“更多品牌”动态发现规格；排除高达水贴、BUILDERS PARTS、可动底座、高达模型配件套组，剩余17个模型品牌；同品牌中的独立武器/扩张零件/灯组/骨架等配件及非高达作品也排除。
- 规格模式：选择品牌/比例，固定的常规商品、线上售卖、高达基地限定、活动限定标签原地切换；分类取官网筛选结果，不能靠商品名猜限定类型。
- 作品模式：打开年代分组作品选择器，选作品后合并所有销售类型；切换模式清除另一模式的限定条件。支持名称搜索、20/40/60/100分页，默认20，桌面5列，独立保留筛选/页码/位置。
- 卡片仅显示官网对应封面并铺满图片框；详情展示该商品全量图库/正文详细图，可点图放大，仅保留名称、大图、官方人民币价格、日本日元价格、发售日期，无来源链接。缺价显示未公布，不换算；月级日期不伪造到日。
- 高达入口左侧活动预览、右侧发售预告；移动端堆叠。活动展示线上/线下/结束状态；预告关联对应模型。左/右模块仅出现在高达页面。

## 方案设计
### 既有模块复用与隔离
独立GunplaEntry表承载product、brand、series、event、announcement的JSON资料（与现有TomicaNews/PokemonDetail风格一致），source_key和kind唯一。GunplaRepository独立实现查询，使用现有CatalogCache.snapshot仅保留一份gunpla列表摘要，列表不携带整套图库；详情单独缓存。业务修订写现有CatalogRevision的gunpla行，不动旧图鉴快照。

新增0005_gunpla迁移，仅建新表。图片注册既有ImageAsset；只增加staticcdn.bandaihobbysite.cn到严格白名单，复用受保护reference-images、Redis热缓存和30天磁盘缓存。图片仍为私有预览引用，不变更rights_status，不开放匿名图片。内部回环读取白名单增加/api/gunpla，不放宽管理和注册边界。

### 官方采集
backend/app/sources/gunpla.py负责纯解析，scripts/sync_gunpla.py负责串行2秒限速、robots、失败重试、原始HTML缓存、断点manifest、增量/全量及导出/入库。复用SourceHttpClient并为gunpla增加精确HTTPS主机、路径与page/tag查询校验。首页动态读取品牌和作品/logo，四类筛选逐页收集并按官方商品ID去重，另核对未筛选索引覆盖；仅发现品牌目录，不跟“相关商品”扩散。逐商品读取图库主区域与商品信息正文图片，排除缩略重复、相关推荐、logo、页脚及二维码。图片URL保持官方原图地址，独立封面与图库互不混淆。语义摘要幂等，失败保留旧数据并记录collection日志与私有进度。

完整采集启动后与后端/UI开发并行运行同一受限爬虫进程，不委派额外编码代理。独立项目定时器每日03:30增量，缓存超过7天的详情重查；全量命令显式刷新。旧worker/scheduler行为保持原状。预热器补入高达详情和所有登记图片，封面优先，真实报告进度，不把运行中/失败图片宣称全量完成。

### 接口
/api/gunpla/filters 返回品牌、比例、销售类型与按年代的作品；/api/gunpla 返回分页摘要；/api/gunpla/products/{official_id} 返回完整图库和三个资料字段；/api/gunpla/home 返回活动和按发售月组织的预告。均受既有会话保护，不在结果中提供可点击来源URL。年代表仅使用核实的公开年代，未确定/非影视企划独立分组，不根据商品发售年份推断作品年代。

### 客户端
浏览器独立/preview/gunpla.html、gunpla.js、gunpla.css，复用当前导航、账号控件、图鉴基础主题与图片查看器风格。只在旧侧栏追加第三个链接，不改旧Tomica/Pokemon状态机；新页面自己保存高达筛选与详情返回位置。网页登录next已有/preview/白名单，自动支持高达页。原生小程序增加高达列表/详情与第三个tab，复用会话、private-image和认证下载组件，保留两个旧页面契约。
